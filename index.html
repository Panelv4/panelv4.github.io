Public vulnerability disclosures

Three advisories published through the OpenJS Foundation CNA in November 2026. Severity, CVSS vectors, affected versions and fixed versions follow the maintainers' public GitHub Security Advisories. Reported by Dhairya Sharma (Panelv4).

CVE-2026-120213 · GHSA-h3vp-4jfr-v364

Prefix escape via decoded route parameters in @fastify/http-proxy

CRITICALCVSS 9.1CWE-22 · CWE-436

URL-decoded route parameters are substituted into rewritePrefix without re-encoding. An encoded / plus # or ? injects extra upstream segments and strips the mandatory suffix — no .. needed. Leads to SSRF or authorisation bypass.

Affected >= 9.0.0, < 11.6.6  ·  Fixed 11.6.6  ·  Workaround none
Advisory ↗ NVD ↗ Dhairya Sharma — write-up ↗
CVE-2026-117518 · GHSA-vp2r-3vgv-32g9

Backslash dot-segment prefix escape in @fastify/reply-from

HIGHCVSS 8.2CWE-22

buildURL() checked only forward-slash dot-segments, while the WHATWG URL parser normalises \ and %5c to /. Backslash dot-segments bypass the check and resolve to another upstream path, escaping the intended proxy prefix.

Affected <= 12.8.0  ·  Fixed 12.8.1  ·  Workaround none
Advisory ↗ NVD ↗ Dhairya Sharma — write-up ↗
CVE-2026-116592 · GHSA-mqg3-3v4r-cm32

Cache poisoning & cross-user disclosure via intermediate redirects in undici

HIGHCVSS 7.4CWE-346 · CWE-524

With an originless Agent, a shared cache and compose(redirect(), cache()), only the final redirect hop is inspected. Intermediate Vary, no-cache and origin policy are lost, so user-specific responses can be cached under a trusted key and served to another user.

Affected 7.30.1, 8.12.2–8.12.3  ·  Fixed 7.30.2 / 8.12.4
Advisory ↗ NVD ↗ Dhairya Sharma — write-up ↗
